**Catatan pemakaian:**  
- Beberapa referensi adalah **proceeding konferensi** (mis. EPJ Web of Conferences, Springer CCIS, OASIcs)—tetap lazim dipakai dalam sitasi akademik.  
- **Kaitan ke subbab** bersifat interpretatif: jelaskan di naskah Anda mengapa referensi tersebut relevan dengan sistem Griya Satu Mimika.  
- Selalu **unduh ulang PDF** dan ikuti **panduan sitasi** kampus (APA/IEEE/Vancouver).

## 2.2 Arsitektur client–server dan pola MVC

| Field | Isi |
|--------|-----|
| **Penulis** | C. Castillo, O. Castellanos |
| **Tahun** | 2026 (First online: 15 February 2026; konferensi ARTIIS 2025) |
| **Judul lengkap** | Empirical Evaluation of MVC Frameworks: Performance, Scalability, Developer Experience and Learning Curve |
| **Jurnal/Buku** | *Communications in Computer and Information Science*, vol. 2792. Springer, Cham (Proceedings ARTIIS 2025) |
| **Tautan** | https://link.springer.com/chapter/10.1007/978-3-032-16851-1_24 — https://doi.org/10.1007/978-3-032-16851-1_24 |
| **Abstrak** | The study evaluates seven widely adopted MVC-related technologies: Laravel and Symfony (PHP); Django and Flask (Python); Spring Boot (Java); React and Angular (JavaScript/TypeScript). A multi-criteria decision-making (MCDM) model balances objective performance (latency, throughput, memory, scalability, CPU under concurrency, using tools such as Apache JMeter and Locust) with subjective developer experience from surveys of 150+ professionals, documentation review, and DevOps/cloud readiness. **Results:** No single framework dominates; Spring Boot excels in throughput and scalability; Laravel and Django excel in learning curve and documentation; React and Angular offer different front-end trade-offs. **Contributions:** Reproducible MCDM-based selection framework, validated deployment profiles, and an open-source benchmarking toolkit. |

## 2.7 Basis data relasional dan migrasi skema

| Field | Isi |
|--------|-----|
| **Penulis** | Torben Eckwert, Michael Guckert, Gabriele Taentzer |
| **Tahun** | 2025 (Published online: 26 November 2025) |
| **Judul lengkap** | EvolveDB: evolving relational database schemas in a model-driven way |
| **Jurnal** | *Software and Systems Modeling* |
| **Tautan** | https://link.springer.com/article/10.1007/s10270-025-01341-x — https://doi.org/10.1007/s10270-025-01341-x |
| **Abstrak** | Software requirements evolve, often forcing changes to the domain model and relational database. **Schema evolution** and data migration are error-prone when done with manual low-level SQL. The paper presents **EvolveDB**, a **model-driven** approach: administrators compare two schema models (from reverse engineering or edited models), and the tool derives differences and generates executable **data migration** scripts. Evaluation on the MediaWiki schema reports promising usability. The article positions this relative to operator-based tools and mentions ecosystem tools such as **Liquibase** and **Flyway** (conceptually aligned with **versioned migrations** seperti di Laravel). |
